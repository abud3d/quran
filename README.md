# القرآن الكريم

قارئ قرآن عربي متجاوب مع القراءة والاستماع والتفسير.

## بيانات القرآن
- تُبنى ملفات السور الـ114 تلقائياً من إصدار `quran-uthmani` عبر AlQuran Cloud.
- ملف مستقل لكل سورة داخل `quran-data/001.json` إلى `quran-data/114.json`، مع فهرس `quran-data/index.json`.
- خطوة البناء تتحقق من وجود 114 سورة، ومجموع 6,236 آية، ومطابقة عدد الآيات لكل سورة، وتسلسل أرقام الآيات قبل النشر.
- الموقع يجلب ملف السورة المطلوبة فقط ويخزنه محلياً؛ التحميل الكامل يظل اختيارياً.

## الاستماع
- تشغيل الآيات بالتتابع من CDN الخاص بـ AlQuran Cloud.
- اختيار القارئ، مع تمييز الآية الجاري تشغيلها.
- الصوت يُحمّل عند الضغط على الاستماع فقط ولا يدخل ضمن ملفات بيانات القرآن.

## التفسير
- يُجلب التفسير عند الطلب فقط.
- الخيارات: التفسير الميسر، تفسير الجلالين، والتفسير الوسيط.
- يُعرض التفسير منفصلاً عن نص القرآن مع إظهار مصدره.
- التفسير الميسر من مجمع الملك فهد لطباعة المصحف الشريف؛ تُراجع شروط المصدر قبل أي إعادة توزيع محلية.

## أوضاع القراءة
1. **مباشر:** تحميل السورة من ملفات المستودع عند اختيارها.
2. **تحميل السورة:** حفظ السورة الحالية محلياً.
3. **تحميل القرآن كاملاً:** لا يبدأ إلا بطلب المستخدم.

## المصادر
- نص القرآن والتفسير: [AlQuran Cloud API](https://alquran.cloud/api)
- ملفات الصوت: [AlQuran Cloud CDN](https://alquran.cloud/cdn)
- التفسير الميسر: [مجمع الملك فهد لطباعة المصحف الشريف](https://qurancomplex.gov.sa/quran-dev/)

## النشر
GitHub Actions يبني ملفات السور ويتحقق منها ثم ينشر الموقع عبر GitHub Pages.

## تنبيه
هذا المشروع أداة قراءة إلكترونية، ويُرجى الرجوع إلى المصحف المعتمد عند المراجعة والحفظ.
