# القرآن الكريم

موقع ويب عربي متجاوب لقراءة القرآن الكريم بالرسم العثماني.

## التشغيل
افتح `index.html` في متصفح حديث، أو انشر محتويات المستودع على GitHub Pages.

## البيانات
- النص القرآني وبيانات السور تُحمّل عند الاستخدام من واجهة AlQuran Cloud العامة.
- إصدار النص المستخدم: `quran-uthmani`.
- توثيق الواجهة: https://alquran.cloud/api
- هذا المشروع لا يخزن النص القرآني محلياً ولا يعدّل النص الوارد من المصدر.

## المزايا الحالية
- فهرس السور الـ114.
- قراءة السور بالرسم العثماني.
- البحث في نص الآيات.
- متابعة آخر سورة تمت قراءتها محلياً.
- الوضع الليلي والتصميم المتجاوب.

## النشر
المستودع مجهز بسير عمل GitHub Actions للنشر على GitHub Pages. من إعدادات المستودع تأكد أن Pages يستخدم **GitHub Actions** كمصدر للنشر.

## تنبيه
الموقع أداة قراءة إلكترونية. يُرجى الرجوع إلى المصحف المعتمد عند المراجعة والحفظ، والتحقق من النص ومصدره قبل اعتماد الموقع للاستخدام العام.
