# القرآن الكريم

قارئ قرآن عربي متجاوب بثلاثة أوضاع استخدام.

## أوضاع القراءة
1. **قراءة مباشرة:** يجلب التطبيق السورة عند اختيارها فقط، ولا ينزّل القرآن كاملاً تلقائياً. السورة التي تُفتح تُحفظ مؤقتاً على الجهاز.
2. **تحميل السورة:** يحفظ السورة المحددة لتكون متاحة دون إنترنت.
3. **تحميل القرآن كاملاً:** لا يبدأ إلا بطلب المستخدم، مع عرض تقدم التنزيل.

## العمل دون إنترنت
- بعد حفظ سورة، يمكن فتحها دون اتصال من نفس المتصفح والجهاز.
- بعد اكتمال تحميل القرآن كاملاً يمكن قراءة جميع السور دون اتصال.
- البحث المباشر يستخدم الخدمة عند توفر الإنترنت؛ دون اتصال يبحث في السور المحفوظة فقط.
- مسح بيانات الموقع أو المتصفح قد يحذف النسخ المحفوظة.
- يجب فتح الموقع عبر GitHub Pages/HTTPS لتفعيل Service Worker.

## مصدر النص
- النص بالرسم العثماني من AlQuran Cloud، إصدار `quran-uthmani`.
- التوثيق: https://alquran.cloud/api
- لا يعدّل التطبيق النص الوارد من المصدر.

## النشر
المستودع مجهز للنشر عبر GitHub Actions. تأكد من اختيار **GitHub Actions** في إعدادات GitHub Pages.

## تنبيه
الموقع أداة قراءة إلكترونية. يُرجى الرجوع إلى المصحف المعتمد عند المراجعة والحفظ، والتحقق من النص ومصدره قبل اعتماد الموقع للاستخدام العام.
