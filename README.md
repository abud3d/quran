# القرآن الكريم

موقع ويب عربي متجاوب لقراءة القرآن الكريم بالرسم العثماني، مع دعم الاستخدام دون اتصال بعد اكتمال التنزيل الأول.

## التشغيل
انشر محتويات المستودع على GitHub Pages وافتح الموقع عبر HTTPS. لا يكفي فتح `index.html` مباشرة من مدير الملفات لتفعيل Service Worker والتخزين دون اتصال.

## العمل دون إنترنت
- عند أول زيارة مع وجود الإنترنت، تُحمّل بيانات السور الـ114 إلى ذاكرة التخزين المحلية للمتصفح على الجهاز.
- بعد ظهور رسالة **اكتمل تنزيل القرآن على هذا الجهاز** يصبح عرض السور والبحث في الآيات متاحاً دون اتصال.
- ملفات واجهة الموقع الأساسية تُخزّن أيضاً عبر Service Worker.
- يلزم إكمال التنزيل أول مرة قبل قطع الاتصال. مسح بيانات الموقع أو المتصفح قد يحذف النسخة المحلية، وعندها يلزم تنزيلها مجدداً.
- النصوص تُجلب في مرحلة التجهيز الأولى من AlQuran Cloud، ثم تُقرأ من التخزين المحلي؛ لا يلزم الاتصال بالخدمة أثناء القراءة بعد اكتمال التنزيل.

## البيانات والمصدر
- إصدار النص المستخدم: `quran-uthmani` من AlQuran Cloud.
- توثيق المصدر: https://alquran.cloud/api
- لا يعدّل التطبيق النص الوارد من المصدر.

## المزايا
- فهرس السور الـ114.
- قراءة السور بالرسم العثماني.
- البحث المحلي في الآيات بعد اكتمال التنزيل.
- متابعة آخر سورة تمت قراءتها.
- الوضع الليلي والتصميم المتجاوب.
- دعم التثبيت كتطبيق ويب على الأجهزة والمتصفحات الداعمة.

## النشر
المستودع مجهز بسير عمل GitHub Actions للنشر على GitHub Pages. من إعدادات المستودع تأكد أن Pages يستخدم **GitHub Actions** كمصدر للنشر.

## تنبيه
الموقع أداة قراءة إلكترونية. يُرجى الرجوع إلى المصحف المعتمد عند المراجعة والحفظ، والتحقق من النص ومصدره قبل اعتماد الموقع للاستخدام العام.
